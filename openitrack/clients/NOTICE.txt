Game client libraries from opentrack
====================================

The files in this folder are unmodified copies from the opentrack project
(https://github.com/opentrack/opentrack, commit 655c812024a6, bin/ and settings/):

  NPClient.dll, NPClient64.dll         TrackIR-protocol client loaded by games
                                       (source: contrib/npclient/npclient.c,
                                       originally by uglyDwarf of linux-track)
  freetrackclient.dll,
  freetrackclient64.dll                FreeTrack-protocol client loaded by games
                                       (source: freetrackclient/freetrackclient.c)
  supported-games.csv                  game list with the per-game keys
                                       ("facetracknoir supported games.csv")

OpenITrack points the TrackIR and FreeTrack registry entries at this folder
while its "Direct" game output runs, and puts the pose in the FreeTrack shared
memory these libraries read.
